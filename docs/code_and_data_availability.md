# Code and data availability

The Python code used to calculate the discharge-based activation factor, HCI, particle-arrival statistics, and manuscript figures, together with the LISFLOOD-FP parameter files, is available at https://github.com/wkh2430-ops/hci-lisflood-fp-code. No archival DOI has yet been assigned, and the software licence remains to be confirmed by all code contributors.

The HCI figures were generated from the paper-final workbook `三站_20210717零点固定RSE_最终HCI结果.xlsx`. RSE was fixed to its station-specific value at 00:00 on 17 July 2021, and HCI was calculated as `HCI(t) = RSE_fixed × Cq(t)`. Hourly stage and discharge records were supplied for research use by the Yellow River Conservancy Commission of the Ministry of Water Resources and the Sanmenxia Water Control Project. These records and hydrology-derived figure source tables are not redistributed because permission for public release has not been established. The responsible institutions' formal access procedure and the exact data responsibilities of each provider remain to be confirmed.

The river channel, water extent, and in-channel obstructions were delineated from four publicly available Sentinel-1A IW GRD scenes acquired on 15 and 27 July 2021. Their complete product identifiers and acquisition metadata are listed in the repository. The study-area overview used a Copernicus DEM product at 30 m spatial resolution. The LISFLOOD-FP terrain additionally used processed high-resolution ground-elevation data supplied by the Henan provincial mapping institute. The high-resolution and fused terrain products, model boundary and initial-condition files, and model flow fields are not included because their redistribution status has not been confirmed. The national LUCC dataset used to derive Manning's-n grids also remains subject to its original access and licensing terms.

The LISFLOOD-FP executable is not redistributed. The simulations used LISFLOOD-FP 5.8.9; users must obtain the software separately under its applicable terms. The repository documents which external files are required and how authorized local copies connect to the released scripts.
